# CyberRakshak 2.0 Foundation

This branch is the clean construction track for the next major application architecture.

Core principles:
- mobile-first
- privacy-first
- server-side secrets only
- deterministic safety rules before AI interpretation
- source provenance for external information
- graceful operation when AI services are unavailable
- real automated tests for security-critical behavior

The old application remains available as reference material while the replacement is built.
